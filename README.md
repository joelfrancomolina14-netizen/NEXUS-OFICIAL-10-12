 NEXUS — Programación II (UNIFRANZ)

Descripción
NEXUS es un sistema de consola en C# diseñado para aplicar los conceptos clave de la Programación Orientada a Objetos (POO), herencia, polimorfismo, colecciones genéricas (`List<T>`) y consultas LINQ.

El proyecto sirve como base práctica para la preparación del examen de evaluación del Hito 3.

Estructura del Repositorio

- `src/`: Código fuente de la aplicación en C# (`.cs`, `.csproj`, `.sln`).
- `docs/`: Manual técnico completo en formato PDF (`NEXUS_Manual_Tecnico_H3.pdf`) que incluye la arquitectura, diagrama de clases, ejemplos de código, batería de preguntas de examen y el diagnóstico de aprendizaje.


Tecnologías Utilizadas

- **Lenguaje:** C# (.NET Core / Framework)
- **Paradigma:** Programación Orientada a Objetos (POO)
- **Herramientas:** Visual Studio Community, Git / GitHub Desktop
